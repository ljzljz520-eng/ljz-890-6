使用说明

  • 回忆审核：学生提交的回忆默认不公开，在此通过或退回；学生留下的联系方式仅您可见。
  • 大事记 / 照片 / 寄语：维护公开页内容，修改保存后即时生效。
  • 站点与倒计时：设置学校班级、毕业日期与公开页公告，倒计时自动计算。
  • 导出留档：可导出完整 JSON 归档（含照片与联系方式）、回忆明细 CSV、公开版 Markdown 编年。
  • 公开页面不会展示任何联系方式，公开版编年导出同样不含隐私信息。

隐私与留档说明

  • 服务器数据保存在 data/db.json，上传的照片保存在 uploads/ 目录。
  • 建议每学期末下载一次完整 JSON 归档，毕业后随班级资料永久保存。
  • 公开页、公开下载链接均自动过滤联系方式字段。
